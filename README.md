# Навигатор продаж

Основное приложение продавца для подключения Ozon и Wildberries, каталога товаров, аналитики, финансов и ИИ-помощника.

## Развёртывание на Render

Для бесплатного Web Service Render блокирует исходящие SMTP-подключения. Для отправки писем подтверждения и сброса пароля используйте HTTP API:

- задайте `BREVO_API_KEY` в переменных окружения Render;
- задайте `BREVO_SENDER_EMAIL` как адрес подтверждённого отправителя в Brevo;
- при необходимости задайте `BREVO_SENDER_NAME` (по умолчанию «Навигатор продаж»);
- оставьте `APP_ORIGIN` равным публичному HTTPS-адресу приложения.

Когда `BREVO_API_KEY` установлен, приложение отправляет письма через Brevo HTTPS API. Без него сохраняется SMTP-режим для локального запуска и хостингов, где SMTP доступен. Не храните ключ Brevo в Git и не отправляйте его в чат.
